info Pipeline Data Flow Summary

Processing Pipeline

  1. Camera frame captured at ~4 FPS (320×240 downsampled JPEG)
  2. Simultaneous audio F0 pitch extraction via autocorrelation
  3. Speech-to-text via Web Speech API continuous recognition
  4. Three parallel analysis engines produce emotion probability vectors
  5. Late-attention fusion produces a unified emotional state
  6. Risk scorer classifies into 4 ISRO-defined severity tiers
  7. Interventions triggered automatically at Level 1+ risk
  8. Ground alerts dispatched at Level 2+ via encrypted S-Band relay

Key Technical Innovations

  • ✦ Graceful Degradation: System operates with any 1 of 3 modalities active
  • ✦ Cross-Modal Discordance Detection: Identifies masked distress (e.g., smiling face + stressed voice)
  • ✦ Personalized Baselines: Per-astronaut calibrated heart rate, pitch F0, and EAR resting values
  • ✦ 5 Flight Simulation Presets: Pre-configured scenarios for live demonstration
  • ✦ Real-Time TTS: Browser-native speech synthesis for AI companion responses
  • ✦ Tactical Breathing Pacer: Integrated guided box-breathing intervention widget
